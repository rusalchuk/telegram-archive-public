# Telegram Archive

Telegram Archive is a personal-use tool that archives messages accessible to the account owner's Telegram account into the account owner's Google Drive.

The application uses Google OAuth solely to create, retrieve and update its own archive files using the `drive.file` scope. The archive is not a public messaging service.

- Source code: [Private personal project](https://github.com/rusalchuk/telegram-archive)
- [Privacy Policy](privacy.md)

This page describes the intended configuration of the personal project, not an offered commercial service.
