Privacy Policy — Telegram Archive

Last updated: November 3, 2026

Purpose

Telegram Archive is a personal-use application intended to copy Telegram messages available to its owner into that owner's Google Drive for searching and summarization.

Data processed

The application can process message text, captions, Telegram message identifiers, timestamps, sender identifiers, and source links. Google OAuth credentials are used to authorize access to the owner's Drive.

Google data access

The application uses only the Google Drive drive.file scope to create, read and update its own archive and synchronization-state files; it does not request permission to access unrelated Drive documents.

Storage and sharing

The archive is stored in the owner's Google Drive. The workflow runs using GitHub Actions, and Telegram is the source of messages. No archive is intentionally sold or shared with advertisers. If the owner independently connects Drive to ChatGPT, that access is initiated by the owner and subject to the corresponding service settings.

Retention and deletion

Data remains until the owner deletes the relevant files from Google Drive. The owner may revoke Google authorization in Google Account settings and remove GitHub Actions credentials to stop access.

Security

Secrets are intended to be stored in private GitHub Actions secrets, not public source files. No security measures guarantee absolute protection.

Contact

Contact the project owner using the GitHub profile.

This page describes intended personal-use functionality; it does not assert the application is deployed.
